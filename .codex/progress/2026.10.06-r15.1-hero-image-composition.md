# R15.1 Hero Media Composition Correction

基线：main @ 242683a9b146310afc726559f1c5f68fe8545497

## Root cause
- `assets/images/hero/hero.webp` 实际尺寸为 1200×547。
- `index.html` 原先声明为 1200×900。
- `css/sections.css` 原先将 Hero 图片强制为 4:3；横屏响应式又覆盖为 16:10。
- Android 因此以错误的媒体比例渲染 Hero 图片，导致横向内容被裁切，视觉占比与用户感知的“通铺”不一致。

## Fix
- HTML 图片尺寸声明改为真实 1200×547，并升级 Hero 资源缓存版本到 r151。
- Hero 图片唯一比例契约收敛到 1200/547。
- 删除 landing/responsive 中重复或冲突的 4:3 / 16:10 Hero 比例覆盖。
- 浏览器 smoke 增加 Hero 图片原始尺寸、容器占用率和渲染比例回归检查，并补充 412×915 移动端。
- 保留现有 Logo、品牌色、核心公开文案、导航控制器、生态布局及 Cloudflare Workers Static Assets 架构。

## Validation gate
- Static validator
- Wrangler deploy --dry-run
- Chromium smoke matrix: Desktop / Laptop / Tablet portrait / Tablet landscape / Mobile 390×844 / Mobile landscape 844×390 / Small mobile 360×800 / Large mobile 412×915

## Acceptance
Hero 图片在 Android/移动端完整占用媒体容器宽度，并以资源原始比例显示，不再因响应式固定比例产生无意义裁切或大面积视觉空白；其他终端无布局回归。
